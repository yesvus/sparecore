# Contributing

SpareCore is experimental and prioritizes the owner's interactive use.

- Keep policy decisions deterministic, tested and dependency-free.
- Reuse mature tools rather than writing custom schedulers or leases.
- Run: python3 -m unittest discover -s tests -v.
- Never commit user data, private node addresses or secrets.
- Privileged installers, cluster enrollment, network rules and worker
  actuation require explicit review.
